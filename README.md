# 📡 Eureka Service Discovery

This is the **Eureka Server** for the microservices architecture. 

It acts as the service registry, allowing services to register and discover each other dynamically.

## 📝 Description

Eureka is part of the Netflix OSS stack and enables service discovery for Spring Boot microservices. 
This server acts as a central hub for all services to register themselves and look up other services.
